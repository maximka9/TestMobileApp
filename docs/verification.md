# Проверка SASAclicker 0.1.0

Дата: 2026-09-05. Папка: `R:\Python\Sasavot`.
Движок: `4.7.2.stable.official.ed1daf0bf`, Standard, Windows x64.
Рендерер: OpenGL Compatibility, NVIDIA GeForce RTX 3060.

## Автоматические проверки

- `tests/test_runner.gd`: **99 passed, 0 failed**.
- Импорт проекта и запуск главной сцены: без parser/runtime errors.
- Включены `untyped_declaration` и `treat_warnings_as_errors`.
- `restart_probe.gd`: запись в первом процессе **PASS**, загрузка во втором **PASS**.
- `visual_smoke.gd`: **0 failures**; проверены границы UI на 360×640,
  360×800, 540×960 и 720×1280, ввод мышью через viewport даёт один клик.
- JSON round trip, реальная запись/замена файла, backup повреждённого JSON,
  недоступный путь, лимит retry и ручное восстановление проверены тестами.
- В тесте полного цикла новый игрок с нулевым балансом проводит 500 игровых
  секунд, делает 1500 кликов, зарабатывает на коллаб и микрофон, завершает эфир
  и восстанавливает прогресс из сохранения.

Тесты с виртуальным временем проверяют баланс без ожидания реальных минут.
Renderer smoke использует настоящий GPU и дерево Godot. Скриншоты комнаты,
LIVE, выбора контента, upgrades, события и summary формируются в `build/checks/`;
комната, LIVE, выбор контента и summary также проверены визуально.
Скриншоты представляют внутренний viewport; физическое окно может иметь поля
из-за integer scaling. Тестовые сохранения изолированы от обычного прогресса.

## Ограничения проверки

APK **не собран**: JDK 17 доступен, Android SDK не найден, `adb`/`sdkmanager`
отсутствуют в PATH. При импорте Android-профиля редактор сообщает
`Unable to open Android 'build-tools' directory.` Это диагностика отсутствующего
toolchain, а не ошибка GDScript. Инструкция установки находится в README.

На физическом Android не проверены touch, safe area, пауза ОС и 60 FPS.
iOS не собирался: требуется macOS/Xcode. Результаты desktop-рендерера
не являются измерением производительности телефона.

## Повторный запуск

```powershell
.\tools\test.ps1 -Visual
```

Проверка запускает импорт, основной набор тестов, отдельные процессы записи/
чтения и рендерер. Ошибки тестов, `ERROR:`, `WARNING:` и `SCRIPT ERROR:`
прерывают проверку. Сообщение об отсутствующем Android build-tools отдельно
описано выше; оно не препятствует запуску desktop-проекта.
