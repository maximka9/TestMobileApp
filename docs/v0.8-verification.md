## Changed legacy contracts

- Threshold 50 at level 1 becomes 100; remainder and multiple-level tests remain.
  Session XP accounting includes increasing level XP. The 55-click restart fixture
  now expects level 1 / XP 55, rather than obsolete level 2 / XP 5.
- Recovery boundary tests assert continuous 10/min instead of whole-minute 2/min.
  Fractional intervals, negative clock movement, caps and live exclusions remain.
- Historical saves retain level, inventory and career state; XP is compared to
  its migrated percentage rather than the old absolute integer. Schema 11 is
  idempotent and does not migrate twice. Transient cosplay never resumes from save.
- Cooking starts directly, then the existing cosplay is activated through Moves.
  Obsolete conditional calls to the removed pre-stream UI were removed from smoke
  scripts; all original start/location/input assertions remain.
