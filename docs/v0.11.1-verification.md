# SASAclicker 0.11.1 verification

Scope: room presentation, navigation theme, definition icons and achievement UI.
No gameplay service, numeric balance, prerequisite, candidate rotation or save
schema change. Existing real Twitch avatar assets and attribution remain intact.

## Implementation

- Status monitor projected toward the character; keyboard and mouse drawn in a
  shared desk perspective, without mirroring the old sprites. Nearest filtering
  and character proportions preserved.
- Filled BottomNavButton variant with separate normal, pressed and disabled styles.
- Optional definition icons for streams, short forms, moves and cosplay; shared
  header rendering and a controlled fallback. Textures are cached Godot resources.
- Deterministic 64x64 achievement nodes. Depth equals maximum prerequisite depth
  plus one; sorted subtrees occupy separate columns. Orthogonal shared buses join
  prerequisites. Compact toolbar retains 60–180% limits, pan, pinch and Fit.
- Achievement detail popup explicitly uses the shared opaque panel theme.

## Checks

- `tests/v0111_layout.gd`: 27 nodes, zero overlaps, zero foreign-node segment
  intersections, zero avoidable crossings, nodes/connections inside graph bounds.
- `tests/v0111_visual.gd`: compact nodes, fallback icons, navigation states,
  monitor states, 27/27 nodes reachable at each of 60%, 100%, 180%.
- Existing typography, v05 and v07 UI checks retain their original purpose;
  expectations now account for status-only monitor and icon header containers.
- Full `tools/verify.ps1`: all previous suites plus new suites, zero failures.
  Earlier attempts exposed obsolete UI structure/font expectations; each was
  corrected and checked separately before the successful full run.

Evidence: [desktop screenshots](v0.11.1-screenshots/),
[Android screenshots](v0.11.1-android/), [targeted audit](v0.11.1-audit.md).

phone performance is outside this verification. APK/build logs remain ignored in

The retained 0.11.0 schema-12 save loaded without loss of progression. Only offline

compatibility and reset/restart regressions remain in the full suite.
