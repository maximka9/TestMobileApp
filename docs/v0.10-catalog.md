# Offline catalog snapshot

Followers, average viewers and interests are snapshot data. They are not guaranteed
to equal current live Twitch values. Runtime rotation never contacts Twitch.
`stats_updated_at` records the snapshot assembly/check date, not a live-stat guarantee.
`followers = -1` means unknown and renders as «нет данных»; zero means a known zero.
Unverified categories remain empty. `collab_formats` is gameplay configuration and
does not populate public `interests`.

The existing 473 profiles retain their IDs and average-viewer values. heliN139 is
added from the public historical statistics snapshot (average 1,824); that cached
average is historical, not a measurement on the check date, 2026-09-10.
[Historical channel statistics](https://twitchtracker.com/helin139/statistics).
