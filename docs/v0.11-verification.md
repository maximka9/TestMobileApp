# SASAclicker 0.11.0 verification

Base: v0.10.1 / 556e69d. Existing visual draft was corrected, not discarded.

## Real Twitch avatars

412 of the 474 catalog profiles have local 150px Twitch avatars, including all six
featured creators. The remaining 62 explicitly use the neutral silhouette fallback.
No generated portraits are assigned to real channels. The unused draft portrait
atlas was removed. Stable creator IDs map to image paths in
`resources/streamers/avatars.json`, with the channel URL, CDN URL, UTC snapshot date,
SHA256 and missing-image reason. Images came from each public Twitch page's
`og:image` metadata, for example [rostikfacekid](https://www.twitch.tv/rostikfacekid)
and [helin139](https://www.twitch.tv/helin139).

`tools/import_streamer_avatars.py` is an offline preparation tool; it is never invoked
by the game. Godot loads the bundled images through its resource cache. Avatars use
linear filtering; room pixel art retains nearest filtering.

## UI changes

All 27 achievement definitions and 14 event definitions explicitly reference atlas
artwork. Related achievements may intentionally share category art. Tree nodes keep
short completed/secret indicators, distinct state borders and selected highlighting;
details retain the title and description. Toasts use the same definition image.
Primary, secondary, navigation, danger and compact theme variants are shared.

The existing workstation sprite is composed with reversed keyboard/mouse regions;
the desk itself stays fixed. The monitor and its content share one perspective
transform. An imagegen desk experiment was rejected because its checkerboard was
not transparent; that generated image is not used or included in the project.

## Android release smoke: PASS

Final APK: version 0.11.0, code 12; API 35 x86_64 emulator, 1080x1920 portrait,
WHPX with host GPU. Wi-Fi and mobile data were disabled. Checked real avatars and
their frames, list scrolling, options/navigation, native multitouch pinch in/out,
180% limit, Fit to 60%, pan, room composition and illustrated event popup. An event
with insufficient energy displayed its existing error feedback without breaking
the picture, description or skip action. No blocking visual defect or script/crash
error was observed. Physical-device performance was not measured.

The retained 0.10.1 emulator save loaded with the same followers, XP/level, money,
achievements, relationships, upgrades, pending collab and settings. A second
force-stop/relaunch using the normal `GodotAppLauncher` entry point also preserved
these fields and schema 12 (`build/v011-restart-result.txt`).

Evidence: [Android screenshots](v0.11-android/), `build/v011-final-apk.log` and
`build/v011-android-runtime.log`. Final APK SHA256:
`9e52e467a3bd3030a8ec811eb369f7907a0e716b34a24ca871bde0a75eba0a44`.

The full verification's first final attempt encountered two PNG write failures;
the affected v09 smoke and then the entire suite passed on rerun. No gameplay code
was changed to address those artifact-writing failures.
