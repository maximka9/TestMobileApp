## Measured behavior

100 seeded Dota simulations, 100 starting followers, 2 physical clicks/real
second, 30-game-minute sessions with rest between them: **120-click median**
to first organic follower growth. This is a controlled simulation, not player
telemetry. The 0.6 ordinary-stream path has no organic award: baseline still
has zero after 1200 clicks. A finite baseline median or exact 2x ratio cannot
be inferred; the requested absolute ≤400–500 target is met.

Organic growth tests cover quality, audience, duration, novelty, reputation,
career tier, stochastic short-session outcomes, duration cap, zero-online/idle
cases, one-time reward and stronger TikTok/collaboration gains.

Clock tests cover 0/1/30/59/60/90/360 seconds, explicit summary units, monotonic
foreground catch-up independent of frame delta, fresh session tick origin,
and separate 60-second rest recovery. UI checks cover all four automatic scene
mappings, summary return, bounded chat, monitor geometry and no location selector.

Rotation tests cover 0/119/120 deadlines, ten visible changed cards, countdown
reset, fixed-RNG anti-repeat, deferred details refresh, closed/reopened lists,
and incoming-poll isolation. Production events reject unknown/conflicting
creator references and negative named-creator events.
