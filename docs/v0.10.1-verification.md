## Android export integrity defect found during smoke

The first APK visually marked children available with 0/27 achievements. Inspection
of its binary `followers_1000.res` confirmed that the serialized `parent_ids` value
was absent, despite `PackedStringArray("followers_100")` in the source resource.
Binary text-resource conversion is now disabled; resource loading/scene architecture
and authored data are unchanged. The rebuild passes `tools/check_android_resources.py`:
all **74** authored `.tres` files under resources/config match the packaged contents.
The build script now runs this check as a release gate. Android shows locked children
and their edges correctly after the rebuild. This check also protects balance data
against changes introduced by packaging.

The initial SwiftShader emulator configuration failed shader linking and rendered
a blank game. The same APK rendered correctly using host GPU (NVIDIA RTX 3060).
No renderer or shader changes were made to work around the emulator driver.
